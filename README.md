# Fieldnote

Fieldnote is a calm visual search starting point for discovering image references by subject, place, or mood. The warm paper and forest-green palette gives the page the feel of a printed field journal and keeps it distinct from typical image-search interfaces. A two-column editorial introduction pairs the headline with a short note so the page feels like a curated workspace rather than a generic search form. Topic chips offer quick inspiration, while the empty-state prompt explains what to do before results are added.
